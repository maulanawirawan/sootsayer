# Structure

```
sootsayer/
├─ engine/                    # Rust crate "sootsayer-engine"
│  ├─ Cargo.toml
│  └─ src/
│     ├─ lib.rs               # public API: outlook(), plan()
│     ├─ method.rs            # study constants (RR tables, thresholds, baselines)
│     ├─ model.rs             # input/output types (serde)
│     ├─ outlook.rs           # haze-day classification, duration, expected visits
│     ├─ plan.rs              # clean-air room sizing, district priority
│     ├─ wasm.rs              # C-ABI exports for the browser (JSON in, JSON out)
│     └─ bin/sootsayer.rs     # native CLI used by the MCP server and pipeline
├─ web/                       # Vite + TypeScript + MapLibre GL JS v6
│  ├─ public/data/            # static reference data + replay snapshot (generated)
│  └─ src/
│     ├─ main.ts              # app entry
│     ├─ map/                 # globe, layers, sources
│     ├─ data/                # fetchers for /api and static files
│     ├─ engine.ts            # loads the WASM engine
│     ├─ ui/                  # panels, timeline, legend, i18n
│     └─ wasm/                # built engine .wasm (generated by `npm run wasm`)
├─ api/                       # Vercel functions (cached proxies)
│  ├─ fires.ts                # FIRMS NRT CSV -> filtered JSON
│  └─ air.ts                  # Open-Meteo CAMS grid -> daily means
├─ pipeline/                  # Python (uv): builds web/public/data/*
├─ mcp/                       # Python FastMCP server
├─ docs/                      # METHOD.md, DATA.md, DEMO.md
├─ .kiro/
│  ├─ steering/               # product.md, tech.md, structure.md
│  ├─ specs/haze-clinic-outlook/
│  └─ hooks/
├─ vercel.json
├─ README.md, BUSINESS.md, LICENSE
```

## Where things go
- A new study number or threshold: `engine/src/method.rs` only, with the table
  and page it came from in a comment. Never hard-code it anywhere else.
- Anything that touches the network: `api/` (runtime) or `pipeline/` (build
  time). The engine and the UI rendering code stay network-free.
- Generated data goes to `web/public/data/` and is never edited by hand.

## Data flow
```
NASA FIRMS ──┐                         ┌─> globe layers (fires, smoke, imagery)
CAMS (O-M) ──┼─> api/ (cache, daily) ──┤
             │                         └─> engine.wasm ─> outlook + plan ─> panels
OSM, geoBoundaries ─> pipeline/ ─> web/public/data/ ─┘
                                   └─> mcp/ ─> engine CLI ─> agent answers
```

## Tracked on purpose
`.kiro/` is committed (specs, steering, hooks). Never add it to `.gitignore`.
